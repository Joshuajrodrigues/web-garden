YAPYAP is a React component library for a GitHub-style rich text editor built on ProseMirror.

It supports bold/italic/strikethrough, lists, blockquotes, links, and Markdown-style code blocks, with plugin-style image insertion (paste/drag/drop or toolbar) and a customizable theme. 

The editor’s schema and features are defined via ProseMirror’s **Schema** and plugins. 

YAPYAP exposes a `<YapyapEditor>` React component.
